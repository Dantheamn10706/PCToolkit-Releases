# PC Toolkit - releases

Download **PCToolkit-Setup.exe** from the [latest release](https://github.com/Dantheamn10706/PCToolkit-Releases/releases/latest).

PC Toolkit is three small, ad-free Windows tools:

- **Startup Manager** - startup items, services, scheduled tasks and browser startups, with alerts when something sneaks in.
- **Uninstall Manager** - remove programs and Windows apps, then clean up what they leave behind.
- **Driver Manager** - driver updates from Microsoft's catalog and NVIDIA, with backups and rollback.

Windows 10 (2004+) / Windows 11, 64-bit. Setup installs Microsoft's .NET 10 Desktop Runtime if needed. Installed apps check this page for updates (at most once a day) and update themselves when you click **Update now**.

Each release lists the installer's SHA-256; the apps verify it before running an update. The installer isn't code-signed yet, so Windows SmartScreen may ask you to confirm (More info → Run anyway).
